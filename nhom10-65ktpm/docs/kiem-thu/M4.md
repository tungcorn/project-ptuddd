## PR #12 – Kiểm thử phiên đăng nhập và phân quyền

File test: `src/test/unit/auth_session_test.dart`.

| Test | Kiểm chứng |
| ---- | ---------- |
| `validator catches invalid email, weak password, short/long display name` | Bắt đúng lỗi: email rỗng/không đúng cú pháp, mật khẩu < 6 ký tự, tên < 2 hoặc > 40 ký tự |
| `sign up hashes password with salt and sets admin for first local account` | Đăng ký thành công, tài khoản đầu tiên nhận quyền admin; hash trong store khác plain text, salt không rỗng |

| `guest mode and sign out clears current session` | Chế độ khách có `uid == 'guest'`; sau khi gọi `signOut()`, session `current` bị xóa sạch |

   - **Kết luận:** PR #12 và phần bổ sung kiểm thử UI đã hoàn thành trọn vẹn các yêu cầu kiểm chứng phiên Auth của Issue con #21.
